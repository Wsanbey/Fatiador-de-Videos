# Fatiador de Videos

## Descricao
Ferramenta para cortar e fatiar videos em partes menores.

## Funcionalidades
- Corte de videos por tempo
- Divisao em multiplos partes
- Exportacao em varios formatos
- Interface simples

## Tecnologias
- Python
- MoviePy/FFmpeg

## Uso
```python
python fatiar.py --input video.mp4 --start 00:01:00 --end 00:02:00
```

## Instalacao
```bash
git clone https://github.com/Wsanbey/Fatiador-de-Videos.git
cd Fatiador-de-Videos
pip install -r requirements.txt
```
